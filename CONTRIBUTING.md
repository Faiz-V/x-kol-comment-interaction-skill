# Contributing

Thanks for helping improve the X KOL Comment Interaction Skill.

## Good contributions

- Add a genuinely different editorial angle or domain-specific pattern.
- Improve natural English without making claims more certain than the source.
- Strengthen fact-checking, affiliation disclosure, or anti-spam safeguards.
- Add a compact, clearly hypothetical example that demonstrates a reusable technique.

## Pull request checklist

1. Keep `SKILL.md` concise and procedural.
2. Put extended patterns and examples in `references/`.
3. Do not include real credentials, private account data, unpublished campaigns, or personal information.
4. Avoid engagement bait, impersonation, coordinated amplification, and guaranteed performance claims.
5. Validate the skill folder with the Codex `quick_validate.py` utility before submitting.

By contributing, you confirm that you have the right to share the submitted material.
